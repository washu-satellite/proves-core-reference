# Dev loop artifacts (index)

The loop is `.claude/skills/cdh-cycle/SKILL.md`: requirement → plan → review → **tests written from results only** → code →
verify → post-mortem, one commit per step. Where each kind of information lives, and the rule that keeps it from going stale
(one home per fact; everything else links): `decisions/README.md`.

| Directory / file | Holds | Owner / writer |
|---|---|---|
| `ROADMAP.md` | What is next, standing rules, decisions still owed | orchestrator, after each cycle |
| `decisions/` | Why things were decided (append-only records D-nnn) | orchestrator, when Jesse decides |
| `cycles/README.md` | What each cycle did and where it landed | orchestrator, at cycle close |
| `cycles/cycle-<x>-plan*` / `-review.md` | The plan (normative + advisory) and the harm review with gate evidence and pinned test hashes | planner agent / orchestrator |
| `design/` | Designs that are not yet cycles: `parameter-policy.md` (D-004), `activity-axis.md` (D-005), `stored-data/` (A8) | orchestrator or planner |
| `hardware-procedures/` | HP-01..15 bench procedures for Board-level rows | hw-procedure-writer agent |
| `../dev-loop-findings.md` | Verified facts about the code, append-only | orchestrator only |
| `../requirements-matrix.md` | Generated by `scripts/generate_rtm.py` in the gate; never edited | gate |
